# Entrepreneurship Club

Club website: https://quantumshawn.github.io/entrepreneurship-club/

The whole site is one file, `index.html`. Edit it, commit, push, and GitHub Pages updates the live site in about a minute.

## Common edits

- **Add officers:** search `index.html` for `OFFICERS`, delete the comment's opening and closing lines, and fill in names and roles.
- **Add Instagram:** search for `INSTAGRAM` in the footer and swap in your handle.
- **Change meeting time or room:** it appears in the hanging sign, the footer, and the page description near the top. Search for `3:45` and `Priebe`.
- **Diamond Challenge dates:** in the `diamond-challenge` section. Official rules: https://diamondchallenge.org/competition/
